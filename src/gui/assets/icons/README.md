# Icons

Tabler Icons (3.49.0), outline set, MIT licence (see `tabler/LICENSE`). https://tabler.io/icons

Only the icons the app uses are kept here. To add one, download `icons/outline/<name>.svg` from the same version of the `@tabler/icons`
npm package into `tabler/`, and use it as `Theme.icon("<name>")`. The files are listed by `CMakeLists.txt` with a glob, so re-run CMake after adding one.
